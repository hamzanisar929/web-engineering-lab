## Lab 03: CSS Fundamentals

The new `css-lab/` folder contains `index.html`, `style.css`, `script.js` and an
original nature background in `nature.svg`. All ten exercises from the supplied
Lab 03 manual are demonstrated. The page uses Times New Roman throughout.

```sh
npm ci
npm run start:lab3
```

Open http://localhost:3003 or open `css-lab/index.html` with Live Server.

The media query boundaries are explicit: green below 300px, pink from 300px to
below 400px, red from 400px to below 600px, and blue at 600px or wider. The navbar
stays on one line and scrolls horizontally on narrow screens. The nature banner
stays fixed to the right edge. Hover or focus the transition button to see the
font grow and the button rotate. Reduced motion disables rotation and the loader.

Task 2 / Text properties

Centred and capitalised text

learning css one property at a time

The heading source is lowercase. CSS capitalises each word and centres the text. The whole document uses Times New Roman.

text-align: center; text-transform: capitalize; font-family: "Times New Roman";

Task 3 / Absolute and relative units

The same sizes, three ways

The root font size is 16px. Every outer box below has 25px text and every inner box has 10px text.

Pixels

Outer: 25px
Inner: 10px

em

Outer: 1.5625em
Inner: 0.4em

rem

Outer: 1.5625rem
Inner: 0.625rem

em uses the parent font size when setting font-size. The inner em value is 0.4 × 25px = 10px. rem uses the root font size, so 0.625 × 16px = 10px regardless of the outer size. Pixel values are fixed.

Task 6 / Fixed positioning

Love Nature stays in place

A quiet trail winds through the forest. Beyond the trees, the mountains rise into a pale morning sky. This paragraph provides text before the fixed example.

Love Nature

Scroll through the exercises and notice the nature banner at the right edge. It stays in the same viewport position because it uses position: fixed. Its z-index keeps it above the page content.

position: fixed; right: 0; z-index: 10; background-size: cover;

Task 7 / Flexbox alignment

Centre a box, then override its alignment

Priority: align-self on an individual item overrides align-items on its parent for that item. The main axis remains centred by justify-content.

Grow and rotate on hover
